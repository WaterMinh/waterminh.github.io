### AI Course Assistant

A locally hosted AI-powered learning platform that transforms uploaded course documents into interactive learning resources.

Main features include:

- Course-grounded AI chat
- Multilingual document summaries
- Automatic quiz generation
- PDF export
- Document upload and text processing
- Role-based admin and student interfaces
- Chat history
- Summary and quiz caching

**Technologies:**  
Python, FastAPI, MySQL, SQLAlchemy, Docker, Jinja2, JavaScript, LM Studio

**Repository:**  
[AI Course Assistant](https://github.com/WaterMinh/ai-course-assistant)

### Hotel Management Database

A MySQL-based hotel management database covering reservations, payments, housekeeping, maintenance requests, staff, and reporting workflows.

The project demonstrates:

- Relational database design
- Primary and foreign key constraints
- Stored procedures
- Triggers
- Reporting views
- Booking conflict prevention
- Checkout and housekeeping automation
- Seed data and test scripts

**Technologies:**  
MySQL, SQL, Stored Procedures, Triggers, Views, MySQL Workbench

**Repository:**  
[Hotel Management Database](https://github.com/WaterMinh/hotel-management-database)

---

### LINE OpenAI Chatbot

A context-aware LINE chatbot integrated with the OpenAI API.

The backend receives messages through the LINE Messaging API, maintains conversation history for each user, generates responses using an LLM, and exposes RESTful endpoints for chat-history management.

Main features include:

- LINE Messaging API integration
- Context-aware conversations
- Per-user chat history
- OpenAI API integration
- RESTful GET and DELETE endpoints
- Webhook testing through Cloudflare Tunnel
- Postman API testing

**Technologies:**  
Python, Flask, LINE Messaging API, OpenAI API, Cloudflare Tunnel, Postman

**Repository:**  
[LINE OpenAI Chatbot](https://github.com/WaterMinh/line-openai-chatbot)

---

### Smart File Organizer

A lightweight Python automation utility that scans a folder and organizes files into categorized directories based on their extensions.

Main features include:

- Directory scanning
- Extension detection
- Automatic folder creation
- File movement
- Basic exception handling

**Technologies:**  
Python, pathlib, shutil, os

**Repository:**  
[Smart File Organizer](https://github.com/WaterMinh/smart-file-organizer)

## Running the Website Locally

Clone the repository:

```bash
git clone https://github.com/WaterMinh/WaterMinh.github.io.git
```

Open the project directory:

```bash
cd WaterMinh.github.io
```

The website can be opened directly by launching:

```text
index.html
```

A local development extension such as Live Server can also be used in Visual Studio Code.

---

## Deployment

The website is deployed through GitHub Pages.

Changes pushed to the `main` branch are automatically reflected on the live website after GitHub Pages finishes rebuilding the site.

Example workflow:

```bash
git status
git add .
git commit -m "Update portfolio content and featured projects"
git push
```
